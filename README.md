# Evently — Advanced Event Management System

## Run
Open `index.html` in a browser, or deploy the whole folder to GitHub Pages.

## Files
- index.html — home
- events.html — search/filter/sort/pagination
- event-details.html — event details
- booking.html — ticket booking + interactive seats + countdown
- bookings.html — my bookings
- admin.html — admin dashboard, events, bookings, customers, reports, settings
- css/style.css — responsive UI + light/dark theme
- js/app.js — all Vanilla JavaScript logic and LocalStorage

No backend or framework is required. Data persists in browser LocalStorage.
